# Trabajo Práctico Módulo 1 - Python Fundamentals

Aplicación interactiva desarrollada en **Streamlit** que integra conceptos fundamentales de programación: listas, arrays con NumPy, dataframes con Pandas, funciones y clases POO con operaciones CRUD.

## Archivos del Repositorio
- `app.py`: Código principal de la aplicación Streamlit.
- `libreria_funciones_proyecto1.py`: Funciones externas para cálculos específicos.
- `librería_clases_proyecto1.py`: Clases orientadas a objetos.
- `requirements.txt`: Librerías requeridas para Streamlit Cloud.
